## About Naked Time

Naked Time is a time management application that seeks to help users to improve their time management practices and focus on completing important value-adding activities. Naked Time provides a set of tools based on popular time management frameworks to help users to manage time. Naked Time provides an implementation of the [Pomodoro Technique](https://en.wikipedia.org/wiki/Pomodoro_Technique) that is intended to help users to hyper-focus on completing important activities. Using the Pomodoro Technique, users focus in 25-minute blocks of time on activities, followed by a short break. The Pomodoro Technique is designed to help prevent burnout by breaking work into small, focused iterations followed by short recovery periods. Using the Pomodoro Technique, users learn to better control their time, avoid interruptions, and prevent burnout. By analyzing their completed pomodoros, users can gain insight into how to improve their estimation techniques and improve their use of time and focus.

Naked Time also implements the timeboxing technique and provides a visualization of time available during the user's day. Naked Time presents a visualization of the user's time available and lets the user schedule the activities that provide the most value. Timeboxing helps the user to commit to the most important activities and ensuring that enough time is available to successfully complete those activities. Naked Time's implementation of timeboxing supports importing calendar information from popular calendar applications including Microsoft Office 365, Google Calendar, and Apple iCloud calendars, and mobile device calendars.
