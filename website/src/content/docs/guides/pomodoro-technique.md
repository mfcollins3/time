---
title: The Pomodoro Technique
description: How the Pomodoro Technique works and how Naked Time applies it.
---

The [Pomodoro Technique](https://en.wikipedia.org/wiki/Pomodoro_Technique) is
built around a simple cycle:

1. Pick a task to work on.
2. Work on it, without interruption, for one 25-minute interval (a *Pomodoro*).
3. When the Pomodoro ends, take a short break.
4. Repeat.

When you start Naked Time, it begins recording a Pomodoro. When the Pomodoro
is complete, an alarm plays.

This guide is a starting point. More documentation will be added as Naked Time
grows.
:::
